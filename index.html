What Roxy processes

Roxy receives Discord interactions and the account, server, channel and message identifiers needed to respond and enforce access. Text supplied to the bot is processed to answer the request. Immediate conversation context may be held temporarily in process memory. Usernames are display information, not authorization. Stable Discord user IDs identify who may manage a note.

Roxy's ordinary language model and speech engines run on the operator's PC. Explicit note-management controls do not call a language model. Where the selected-context feature is enabled, a relevant private typed question may send a bounded selection of your current context to the existing local Qwen model for a private answer. This does not send notes to a cloud AI service, train a model, or record audio. Do not send financial, health, credential or other sensitive records, or private information about someone else. Do not use the bot if you are below Discord's minimum age for your jurisdiction.

Existing optional external GPT assistance and public-lookup routes may process an ordinary non-memory question when enabled by the operator and the applicable command settings. These routes are separate from the local private-note controls and may send the request to the configured provider. Check the current mode before using them; do not put private notes or other sensitive content into external-assistance requests. This policy does not enable those routes or authorize additional sharing.

Explicit notes, not inferred profiles

Where enabled, a clear authenticated instruction to save a nonsensitive note authorizes that specific scoped save. There is no additional generic signup form. Roxy confirms a save only after durable readback. A failed or unknown result is not a confirmed save; review the current notes before retrying.

Notes are limited to information the participant intentionally supplies, such as a requested nickname, favorite game, hobby, preferred address or project note. Roxy does not mine conversation history to infer psychological traits, demographics, relationships or behavioral profiles. A privacy notice does not authorize permanent capture of every message. Discord content is not used for model training.

Your controls

Use the existing private /roxy ask interaction, putting one of these requests in its question field:

  • Privacy or Memory privacy: show the notice and current limits.
  • Remember that I like bass fishing. or Memory save hobby: bass fishing: explicitly request a note.
  • Memory review: privately list current notes and their IDs/revisions.
  • Memory get ID: review a particular note.
  • Memory correct ID REVISION: replacement text: replace the current value, with a revision check.
  • Memory forget ID REVISION: remove that note from active retrieval.
  • Memory delete all: delete active notes and temporary context and disable personal memory. A later explicit new save is a new request for that note, not restoration of deleted history.
  • Memory context: text and Memory context review: explicitly retain/review temporary context for up to 15 minutes.
  • Memory continuity: text explicitly selects a short private discussion summary for up to ten days; Memory continuity review reviews it. This is not automatic conversation recording. Later relevant private typed questions can use selected context without a separate search command. Typed answers remain private. The qualified personal voice release can also use bounded current selected context from that same personal-server scope only in the verified owner-and-Roxy-only Lobby described below.
  • Memory settings shows independent persistent continuity, durable-note, voice and recognition-sample preferences. Change one with Memory FEATURE on/off revision N, using the displayed revision. Disabling continuity removes your temporary context; disabling durable notes removes those notes. These choices persist across visits. Voice/sample preferences alone do not activate capture or establish all required recording permission. Roulette controls remain separate.

Ambiguous requests do not authorize guessing which record to change or delete; use review to get the correct ID and revision. Reviews and confirmations use private/ephemeral Discord responses. Mentioning another person does not grant access to their notes. Existing legacy recall controls remain available through /roxy memory actions history, clear-history and recall-off; maintenance-record controls use /roxy review actions status, pause and erase. Contact the operator if a feature is unavailable or a request concerns older copies.

Audio and transcription

In the separate personal-server pilot, incoming listening remains disabled unless the qualified release is installed and the operator explicitly admits their own current voice visit. Joining alone does not start listening. Only that verified Discord account's separately attributed stream is eligible; other people are excluded. The pilot processes short, bounded audio buffers locally with Whisper, generates a response with local Qwen, and speaks through Kokoro in the same voice channel. Ordinary audio is discarded after processing. No raw recordings, recognition-error clips, voiceprints, model training, external inference or durable voice-memory writes are enabled by this pilot. The qualified personal release may retrieve at most three current, relevant notes (1,600 characters total) from the operator's own personal-server memory scope. It may speak an answer based on those notes only after verifying the private Lobby's permissions, current occupants, source revisions and retention. It does not access unrelated private Brain data or notes from another server. An audience or permission change cancels private playback. Ordinary conversation can continue without saved context when that context is unavailable.

Before any later audio-capture session, the operator must qualify applicable consent, disclose what is captured and retained, and provide an accurate capture indicator and a way to stop. Late arrivals must have access to the notice. Unknown or withdrawn consent must prevent affected capture; simply posting this policy or remaining in a channel is insufficient. The existing voice-join text notice and private Privacy request provide this link without unsolicited direct messages.

The qualified personal release uses one normal startup command: join Lobby and enter /roxy start in #general. This authenticated command explicitly requests transient listening for the operator's own current visit; it does not authorize anyone else's stream. Internal short-lived permissions renew only while the same visit and current permissions remain valid, within bounded usage limits. Departure, disconnection, withdrawal, an expired or failed permission check, or restart stops listening. After a stopped session, another explicit /roxy start is required. Optional settings controls remain available but are not a normal startup sequence. Voice stop immediately stops local listening and requests a persistent OFF preference; an unavailable result must be checked with Voice settings, rather than assumed saved. /roxy leave disconnects the personal pilot. Personal-server preferences and selected notes are separate from existing settings and notes in other servers; startup does not enroll other accounts, restore deleted notes, enable automatic conversation capture, or change another server's preferences. Voice status and the private admission result report availability; the owner has confirmed the personal pilot’s two spoken replies, while live group microphone and human-hearing qualification remains pending.

Immediate voice context is held only in bounded process memory for the admitted speaker and voice channel, for at most fifteen minutes; withdrawal, disconnection and restart clear it. Saved-context answers are not added to that voice history or an audio cache. Possible recognition mistakes can be detected transiently using bounded confidence/error signals and short-lived request hashes; this does not retain audio clips or establish a confirmed correction. The spoken answer is audible to people in that voice channel, so do not provide sensitive or third-party private information. Text notices remain text-only. In the personal pilot, spoken server actions, including roulette, remain unavailable; use the existing permitted slash commands in their configured server.

Qualified group rollout: separate voluntary controls

After controlled installation in the configured group channel, /roxy start is the only routine session-start command. Permission is limited to the disclosed server and channels; it cannot enroll someone else or expand automatically to another channel. /roxy leave remains subject to the session's stop permissions. The operator's report of verbal agreement does not create account-specific permission records.

Only separately attributed, authorized Discord member streams reach local Whisper. Local Qwen and Kokoro provide conversational replies in that voice channel. Ordinary audio is transient and discarded; no clips are retained. Unknown speakers and bots are excluded. One member's withdrawal does not withdraw another's permission. A single bounded speech pipeline processes the first admitted speaker during overlap; overlapping speech may be ignored rather than mixed. Failed or expired authorization stops affected processing. Disconnect clears temporary buffers. These limits mean this release does not promise perfect overlapping conversation or identity recognition beyond Discord's stream attribution.

Channel-shared selected context is separate from voice permission. Private /roxy ask requests Context consent, Context privacy and Context off manage your own sharing and recall preference. It can inform spoken replies audible to anyone present there, including later arrivals; do not submit private or third-party information. This does not automatically archive conversations. Shared correct ID revision N: text replaces your selection; Shared forget ID revision N deletes it. Private confirmations return an ID, revision and original expiration deadline. Context off or voice withdrawal removes your active shared selections; other members' records remain separate. Reenabling does not restore deleted selections.

Shared selections expire no later than ten days after their original interaction; reads and corrections do not extend that deadline. Retrieval, restart recovery and cleanup exclude expired or withdrawn content. Relevant group replies use at most three currently authorized shared selections totaling 1,600 characters. Typed speech and Member Roulette

When available in the registered command list, /speak out-loud text: uses local Kokoro to say the supplied plain text to people in the requester's current voice channel. It does not fetch Brain notes or call cloud inference. Input is bounded, mentions and links are rejected, playback is serialized, and /roxy stop cancels it. New command processing does not retain its text or generated audio as a memory. Discord still processes the interaction under its own policies.

/member roulette is a recreational voice-disconnect game, not a server kick or ban. Human participation defaults ON each voice-channel visit. /member roulette-off opts only you out until you leave that channel; /member roulette-on opts you back in. Leaving and rejoining resets participation for an observed new visit. Existing opt-outs are preserved conservatively if a transition occurred while Roxy was offline and cannot be verified. The operator can disable the game. Rules remain available through /member roulette-rules. Roulette participation is not permission to record speech.

The game uses current voice membership, necessary Discord user/server/channel IDs, visit tokens, opt-out state, shuffled selection cycles and bounded operation receipts to prevent repeat actions. It does not store behavioral profiles, conversation contents or recordings. Game/control receipts older than 24 hours are removed on the next corresponding operation; active visit and selection-cycle metadata persists only for safe participation/recovery, with fixed capacity bounds. Cowboy Roulette may play locally generated mechanical cylinder clicks, a western introduction and countdown, then a named exit only after a confirmed disconnect. It uses the selected member’s current public Discord display name for the immediate result; unsafe names use a neutral identifier. Names are not added to a personal profile. Introduction and exit lines rotate without repeats, and no firearm-discharge recording is used. Join, privacy and routine feature announcements are text-only. Spoken roulette activation remains disabled outside a qualified group session with current speaker authorization.

Storage and retention

  • New explicit notes: stored in the existing local Brain ledger, with source interaction, stable subject, audience, timestamps, current revision and consent state. They remain until deleted or no longer necessary for this functionality.
  • Explicit temporary context: excluded from retrieval after 15 minutes; expired contents are purged on startup, requests and a bounded maintenance pass while running.
  • Explicit ten-day selected context, where enabled: at most ten short private selections per member. The original interaction determines expiration; reading or correcting it does not extend the deadline. Retrieval excludes expired context, and cleanup runs on startup, requests and bounded maintenance. Disabling continuity or deleting all removes active temporary context. No blanket history import or conversion of private notes to group sharing is enabled. The separate voluntary channel-shared selections described above use the same original ten-day deadline.
  • Operational receipts: bounded metadata/idempotency receipts are retained for up to 30 days (at most 5,000) and recent audit entries are capped at 200. Deletion/consent markers remain to prevent replay and accidental resurrection.
  • Earlier Roxy recall: pre-rollout group text/speech transcripts and addressed exchanges may exist under their original up-to-10-day retention. Previously explicitly saved facts remain separate. The activated privacy update stops new passive persistent excerpts; it does not bulk-import old history into Brain or silently reset existing records.
  • Earlier maintenance records: audio, transcripts and diagnostics may exist under the previous up-to-seven-day policy, with a 2 GB/20,000-record audio limit and 64 MB diagnostic bound. These are separate from member notes. The activated privacy update disables new maintenance-record capture; separately authorized transient listening does not save new audio files.

New member-note contents and source identifiers are encrypted with AES-256-GCM. The storage key is protected using Windows DPAPI; lookup identifiers are keyed hashes. The application enforces per-member, server/channel and purpose boundaries. This does not promise secrecy from the PC's owner/administrator. Legacy files and preservation backups predate this encrypted namespace and may not have equivalent encryption; they are not made public or imported by this feature.

Forgetting removes active content and prevents current retrieval. Older backup copies and filesystem remnants may persist until separately handled. Code rollback must preserve current deletion/consent state; an older copy must not silently reactivate deleted notes. Ask the operator to handle a request involving backups. Backup retention must not override applicable deletion obligations.
